# Taskboard – To-Do List A responsive to-do list built with plain HTML, CSS and JavaScript. ## Run it 1. open in vs code. 2. Open `index.html`. and use live server. Live Project: ## Features - Add, complete and delete tasks - Light/dark theme toggle; preference saved (defaults to the system setting on first visit) - Filter by All, Pending or Completed - Drag-and-drop reordering (order is saved) - Persistence via `localStorage` - Bonus: due dates with overdue highlighting, inline editing (double-click; Enter saves, Esc cancels), "Clear completed", live pending/completed count, keyboard focus styles, reduced-motion support ## Implementation notes - `Index.html` – Structure of to-do-list - `Style.css` – CSS custom properties drive the themes via `data-theme` on ``; --flexbox/grid with a mobile-first layout - `Script.js` – --state lives in a `tasks` array (`{id, text, done, due}`) --every change saves to `localStorage` and re-renders. --Reordering uses the native HTML5 Drag and Drop API and works on the full list. --tasks are dropped onto the target's position. - `localStorage` access is wrapped in try/catch so the app still works if storage is blocked.
